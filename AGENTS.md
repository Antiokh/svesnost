# AGENTS.md — Svesnost

## Область задачи

Это самостоятельный сайт Astro + Starlight для политических и общественных материалов. Не подключайте напрямую контент, движок, базы данных и runtime RSLive.

При работе с сайтом всегда читайте текущие `README.md`, `astro.config.mjs`, `CONTRIBUTING.md` и затрагиваемые материалы.

## Разделение ответственности

- `src/content/docs/**`: редакционные статьи и страницы.
- `astro.config.mjs`, `src/content.config.ts`, `src/styles/**`, `public/**`: техническая платформа.
- Сведения о политике переносите из RSLive только по отдельной задаче, с проверкой прав и ссылок.
- Не добавляйте кастомные Astro-компоненты, плагины, авторизацию, базы данных, PWA или CI/CD-деплой без конкретной необходимости и согласования.

## Содержание и проверка

Пишите по-русски, ясно и с точными источниками. Разделяйте факт, позицию источника, интерпретацию и мнение. Сверяйте актуальные политические, законодательные и исторические сведения по первичным источникам. Указывайте конкретные даты и не создавайте фиктивные ссылки, публикации, авторства или редакционные роли.

## GitHub

Работайте в ветке `agent/<название>` от актуального `main`; открывайте draft PR. Не коммитьте напрямую в `main` и не выполняйте merge без отдельной просьбы. Перед записью повторно получайте актуальные файлы, перед PR проверяйте diff и статус сборки. Указывайте ограничения проверок.
