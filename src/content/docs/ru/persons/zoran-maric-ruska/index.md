**Зоран Марич** — Минимальная биографическая карточка: лицо названо законным представителем соответствующей организации в реестре политических партий. Из этого не следует, что оно занимает должность председателя.[^1]

- [Единая русская партия](/ru/parties/jedinstvena-ruska-stranka/) — Представитель по государственному реестру (Изученная версия реестра: 31.10.2026)

[^1]: **Документ · представитель по реестру** — [Выписка из реестра политических партий](https://upit.rps.gov.rs/Home/GetPDFReport), 31.10.2026.
