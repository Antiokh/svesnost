**Мирослав Алексич** — проверенный краткий профиль.

## Документированные политические связи

- **[Народная партия](/ru/parties/narodna-stranka/)** — ранее был связан с партией; точный статус устанавливается по источнику.[^1]
- **[Народное движение Сербии](/ru/parties/narodni-pokret-srbije/)** — указан представителем, состояние реестра на 31.10.2026.[^2]

Это начальная биографическая карточка по источникам, а не полная биография. Запись о представителе в государственном реестре сама по себе не подтверждает должность председателя партии.
