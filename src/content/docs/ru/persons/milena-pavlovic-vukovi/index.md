**Милена Павлович** — Минимальная биографическая карточка: лицо названо законным представителем соответствующей организации в реестре политических партий. Из этого не следует, что оно занимает должность председателя.[^1]

- [Сербско-русская партия «Волки»](/ru/parties/srpsko-ruska-partija-vukovi/) — Представитель по государственному реестру (Изученная версия реестра: 31.10.2026)

[^1]: **Документ · представитель по реестру** — [Выписка из реестра политических партий](https://upit.rps.gov.rs/Home/GetPDFReport), 31.10.2026.
