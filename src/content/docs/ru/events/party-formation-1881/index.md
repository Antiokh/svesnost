По публикации Исторического архива Белграда, Народная радикальная партия основана 20 января 1881 года, Прогрессивная — двумя днями позже, а программа Либеральной партии опубликована 13 октября 1881 года.[^1]

Дата события означает начало процесса, а не создание всех трёх партий в один день.

Партии: [Народная радикальная](/ru/parties/narodna-radikalna-stranka-1881/) · [Прогрессивная](/ru/parties/napredna-stranka-1881/) · [Либеральная](/ru/parties/liberalna-stranka-1881/).

[^1]: **Публикация · по архивному обзору** — [Исторический архив Белграда: история партий](https://stalnapostavka.arhiv-beograda.org/en/chapters/political-life/development-of-party-life.html); проверено 14.11.2026.
