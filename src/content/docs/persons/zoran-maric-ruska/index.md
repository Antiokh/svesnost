**Зоран Марић** — Почетна биографска белешка: према изводу регистра политичких странака ово лице је наведено као законски заступник наведене организације. То само по себи не потврђује да је председник странке.[^1]

- [Јединствена руска странка](/parties/jedinstvena-ruska-stranka/) — Заступник наведен у изводу регистра (Прегледана верзија регистра: 31.10.2026)

[^1]: **Документ · регистарски заступник** — [Извод из регистра политичких странака](https://upit.rps.gov.rs/Home/GetPDFReport), 31.10.2026.
