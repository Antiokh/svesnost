После обнове вишестраначја у Србији одржани су избори за Народну скупштину 9. и 23. децембра 1990. Према прегледу Народне скупштине, СПС је добила 194 мандата, СПО 19, Демократска странка 7. На истовременим председничким изборима изабран је Слободан Милошевић.[^1]

Ово је документовани почетак посматраног периода, **пре него што је распад СФРЈ завршен**. Изборни резултат не одређује сам по себи ни правни статус ни каснију судбину странке.
