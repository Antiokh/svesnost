Према изложби Историјског архива Београда, Народна радикална странка основана је 20. јануара 1881, Напредна два дана касније, а програм Либералне странке објављен је 13. октобра 1881.[^1]

Датум догађаја означава почетак процеса организовања, не оснивање све три странке истог дана.

Странке: [Народна радикална](/parties/narodna-radikalna-stranka-1881/) · [Напредна](/parties/napredna-stranka-1881/) · [Либерална](/parties/liberalna-stranka-1881/).

[^1]: **Публикација · ограничено на архивски преглед** — [Историјски архив Београда: развој партијског живота](https://stalnapostavka.arhiv-beograda.org/en/chapters/political-life/development-of-party-life.html); приступ 14.11.2026.
