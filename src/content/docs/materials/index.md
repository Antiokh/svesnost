Этот раздел предназначен для политических и общественных материалов.

Пока публикаций нет. Новые статьи можно добавлять в папку `src/content/docs/materials/` в формате Markdown. Они автоматически появятся в боковом меню.

При публикации различайте подтверждённые факты, позиции участников, интерпретации и мнения. Указывайте проверяемые источники и даты для изменяющихся утверждений.
