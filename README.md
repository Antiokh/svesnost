# Свесност / Svesnost

**Свесност** је самостална тројезична енциклопедија политике и друштва на Astro + Starlight. Основно издање је на **српском језику и ћирилици**, а руски и енглески су изборна, међусобно изолована издања.

## Језичка структура

| Језик | URL | Изворни фајлови |
| --- | --- | --- |
| Српски (ћирилица) | `/` | `src/content/docs/**` изван `ru/` и `en/` |
| Руски | `/ru/` | `src/content/docs/ru/**` |
| Енглески | `/en/` | `src/content/docs/en/**` |

Свако издање има сопствени мени, а Pagefind користи `html[lang]` да одвоји претрагу. Прекидач језика користи стварне везе и ради без JavaScript-а, чак и у мобилном менију. Отвара одговарајућу објављену верзију чланка; када превод не постоји, отвара почетну страницу изабраног језика. Starlight технички генерише fallback URL адресе за необјављене преводе; middleware их уклања из менија, спречава њихово укључивање у Pagefind и обележава `noindex`. Оне не смеју бити повезане као преводи.

## Структурирани подаци

Схема за личности, догађаје, места, изворе, доказе и мултимедију описана је у [моделу садржаја](docs/CONTENT_MODEL.md). Подаци су одвојени од изгледа: Starlight аутоматски додаје хронологије и сродне ставке, а [заједничка карта догађаја](/events/map/) користи објављене координате са статичним fallback-ом. Родослов није главна структура; будући граф веза користи стабилне ID-еве. Нису потребни портрети за сваког човека. За сваку усмерену везу одвојено се приказују њени извори и докази. Измене `slug` и локализоване руте проверавају се у продукционој изградњи.

## Уређивање

Пре рада прочитајте [уређивачку политику](docs/EDITORIAL_POLICY.md), [правила доприноса](CONTRIBUTING.md) и [агентска упутства](AGENTS.md). Главне категорије извора, редом приоритета, јесу **документи → публикације → сведочења → гласине**. Приоритет типа извора никад сам по себи не доказује истинитост конкретне тврдње.

Текстови се чувају у `src/content/docs/`, без зависности од RSLive. Политички чланци из RSLive не преносе се аутоматски.

## Језичка редактура

PR-ови за руске чланке добијају преглед помоћу `humanizer_russian`, а за српске помоћу `humanizer_serbian`. Читају се само параграфи и други видљиви текст тела странице; frontmatter и службена разметка су искључени. Сугестије су необавезујуће, без аутоматског преписивања. Видети [правила интеграције](docs/HUMANIZER_REVIEW.md).

## Локални рад

Потребан је Node.js 24 и npm.

```bash
npm ci
npm run dev
npm run build:data
npm run build
npm run test:i18n
npm run test:model
npm run test:integration  # синтетички подаци се уклањају и сајт се поново гради
npm run test:dev          # провера измена без рестарта Astro dev сервера
npx playwright install chromium  # само при првом локалном покретању
npm run test:ui
npm run preview
```

CI проверава продукциону изградњу, главне језичке URL адресе, статус необјављених превода и навигацију у Chrome-у за мобилни и десктоп приказ. Мобилне splash странице имају теме и језике у заглављу, док остале странице задржавају Starlight Popover; на широком десктопу мени и садржај могу се сакрити одвојено. Тему чува Starlight storage, мени се памти током сесије, а скривени садржај се памти по страници. Зависности су закључане у `package-lock.json`; CI и поновљиве локалне инсталације користе `npm ci`.

## Објављивање и управљање

Сајт је статичан; резултат је у `dist/`. Домен, хостинг и одговорни уредници биће одређени засебно. Спољни аутори шаљу измене преко pull request-ова. Техничка платформа остаје мала: без посебних база података, PWA и модула RSLive.
