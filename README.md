# Svesnost

Самостоятельный сайт на **Astro + Starlight** для материалов о политике и общественной жизни. От RSLive заимствованы базовые визуальные принципы: читаемая ширина статьи, типографика и навигация Starlight. Код, публикация и редакционное управление не зависят от RSLive.

## Быстрый старт

Требуется Node.js 24 и npm.

```bash
npm install
npm run dev
```

Для проверки статической сборки:

```bash
npm run build
npm run preview
```

После первой установки зависимостей рекомендуется закоммитить созданный `package-lock.json`, чтобы дальнейшие установки выполнялись через `npm ci`.

## Структура

- `astro.config.mjs` — штатная конфигурация Starlight и автоматическая боковая навигация.
- `src/content.config.ts` — стандартная коллекция документации Starlight.
- `src/content/docs/` — публикации; файл `index.md` в каталоге формирует маршрут каталога.
- `src/styles/theme.css` — небольшие визуальные настройки, без копирования компонентов RSLive.
- `public/favicon.svg` — локальная иконка проекта.
- `CONTRIBUTING.md` и `AGENTS.md` — правила редактирования.

## Публикация и управление

Сайт собирается статически командой `npm run build`. Результат — каталог `dist/`, подходящий для обычного статического хостинга. Домен и провайдер хостинга пока не установлены, поэтому параметр `site` и автоматический деплой намеренно отсутствуют.

Редакторы работают с материалами в `src/content/docs/` через отдельные ветки и pull request. Изменения конфигурации движка рассматриваются отдельно. Право merge, список внешних редакторов и настройки защиты `main` определяются владельцем репозитория через GitHub.

**Перенос политических материалов из RSLive не входит в этот технический стартовый набор.** Он должен выполняться отдельным PR с проверкой источников, маршрутов, лицензий и ссылок.
